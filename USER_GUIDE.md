# Première utilisation / 新手使用说明

## Le chemin le plus simple / 最简单的用法

L’application démarre maintenant en **mode simple** sur **Me guider**. Suivez le bouton vert. Vous n’avez pas besoin de choisir un outil ou de connecter ChatGPT.

1. **CV** : choisir votre fichier, puis **Enregistrer mon CV et continuer**. Si un CV est déjà actif, cette étape est passée automatiquement.
2. **Offre** : une offre apparaît. Si elle vous convient, **Je choisis cette offre**. Sinon, **Voir une autre offre**. Si aucune offre n’est disponible, indiquez seulement le poste et la ville puis **Chercher des offres**.
3. **Site du recruteur** : le bouton vert ouvre un autre onglet. Cliquez Postuler sur ce site, joignez votre CV, remplissez le formulaire et envoyez. Attendez sa confirmation, puis revenez dans l’onglet de l’assistant.
4. **Confirmation** : cochez la case uniquement si le site ou un courriel confirme l’envoi pour cette offre. Cliquez sur le bouton vert pour enregistrer ce fait ici. En cas d’erreur, la page ne dit pas que c’est terminé.
5. **Terminé** : vous pouvez choisir une autre offre. Vous pouvez fermer et revenir plus tard ; votre étape est conservée. La confirmation d’envoi devra être cochée à nouveau après un rechargement.

**Afficher tous les outils** remet les filtres, la préparation assistée et les paramètres avancés. **Mode simple** permet de revenir. Les paramètres masqués restent enregistrés. Le parcours simple est une candidature manuelle ; le site du recruteur peut demander une connexion ou des réponses supplémentaires.

现在默认打开 **简洁模式 → 一步步带我投递**。只需跟着绿色按钮：

1. 选择本机简历文件，点保存。已经启用简历时自动跳过。
2. 一次看一个岗位。合适就选，不合适看下一个。没有岗位时只填想找的岗位和城市，再点寻找。
3. 绿色按钮打开招聘网站。在新标签页申请、上传简历、填表、提交。看到成功提示后回到助手标签页。
4. 只有看到了网站成功提示或确认邮件，才能勾选确认并保存投递记录。保存失败不会显示完成。
5. 显示完成后，可以再选一个岗位。刷新或以后回来都能继续；发送成功的确认框不会自动替你勾上。

不需要连接 ChatGPT，也不需要理解队列或 AI 规则。网站本身可能要求登录或补充回答。需要高级功能时点 **显示完整工具**，随时可以切回 **简洁模式**；收起配置不会删除原有资料。

Ouvrez **Premiers pas** dans la barre latérale. Choisissez Français si nécessaire. Le guide existe dans les six langues de l’interface ; vous pouvez l’imprimer ou le sauvegarder en PDF. Chaque page contient une aide dépliable.

在应用左侧打开 **从这里开始**。可选法语等六种语言，也可打印或保存指引为 PDF。每页顶部都有可展开的操作说明。

## Exemple à suivre / 跟着例子操作

Dans **Premiers pas**, commencez par **Faire un exemple ensemble**. Une seule étape s’affiche à la fois, avec le bouton à utiliser, un aperçu et le résultat attendu. L’exercice est fictif et ne modifie aucune candidature. Il reprend votre étape après un rechargement. Le bouton vers l’application permet de faire la même action avec vos propres documents ; revenez avec **Revenir à mon exemple**. Les formulaires externes restent sur le site du recruteur. Imprimer le guide inclut les cinq étapes.

在“从这里开始”顶部点 **跟着例子做一遍**。每次只看一步，含操作按钮、例子和完成标准。练习不会修改真实申请，刷新后能继续。可跳到实际页面，用自己的资料做相同操作，再点“返回我的练习”。打印会包含全部五步。

Exemple fictif : Alex postule à un CDD de réception à Paris chez Hôtel Exemple.

| Étape / 步骤 | Action / 怎么做 | Résultat / 怎样算完成 |
|---|---|---|
| 1. CV | Profil → choisir CV_Alex_Accueil.pdf → Ajouter → Activer. 个人资料 → 选择本机简历 → 添加 → 启用。 | CV visible avec ACTIF. 简历在列表中显示已启用，只选择文件还没上传。 |
| 2. Offre / 岗位 | Offres → lire le CDD, horaires et dates → Ouvrir l’offre. 阅读合同、时间和日期 → 查看岗位。 | Offre ouverte sur le site externe ; rien envoyé. 进入招聘网站，尚未投递。 |
| 3. Formulaire / 表单 | Sur le site : Postuler → connexion si demandée → Alex, alex@example.test, CV → vérifier. 在网站申请并登录，填联系方式、上传简历、检查必填项。 | Bon CV joint et champs corrects. 简历版本正确，必填项完整。 |
| 4. Envoi / 发送 | Sur le site : Envoyer → attendre « candidature envoyée ». 点网站的发送并等待成功提示。 | Confirmation du site ou courriel. 网站或邮件确认；断网没返回时不能算成功。 |
| 5. Suivi / 记录 | Revenir → même offre → J’ai déjà envoyé cette candidature / Marquer envoyée. 回来找到同一岗位，标记已投递。 | Carte Envoyée, file Terminée si elle y figurait. 卡片显示已投递；如果在队列，队列显示已完成。 |

Pour une vraie candidature, remplacez Alex et le fichier d’exemple par vos propres informations. Ne renseignez jamais l’adresse fictive dans un vrai formulaire.

真实投递请换成自己的名字、邮箱和简历，不要把虚构示例资料填到招聘网站。

## Je veux simplement postuler / 我只想投递

1. Dans Offres, choisissez une offre et cliquez sur **Ouvrir l’offre**.
2. Sur le site du recruteur, connectez-vous si nécessaire, joignez votre CV et envoyez la candidature. ChatGPT n’est pas nécessaire pour cette voie.
3. Attendez la confirmation du site. Revenez dans **Pipeline & file**, trouvez l’offre et cliquez sur **J’ai déjà envoyé cette candidature**. Ne marquez pas envoyée si vous n’avez pas soumis sur le site.

搜索并选择岗位 → 查看招聘网站 → 上传简历并提交 → 网站确认成功 → 回来记录已投递。无需连接 ChatGPT。关闭网页或自动准备失败后，也能记录已经完成的手动投递。

## Où est mon CV ? / 我的简历在哪？

Le CV doit être disponible sur l’ordinateur où fonctionne l’application. Un CV sur votre autre ordinateur n’est pas synchronisé automatiquement. Dans **Profil & préférences**, choisissez un PDF/DOC/DOCX, cliquez **Ajouter**, puis activez la bonne version. **Télécharger le CV** permet de le récupérer pour une candidature manuelle.

简历需在运行项目的这台电脑上传。进入个人资料，选择文件、添加并启用正确版本。可下载简历再上传到招聘网站。资料、简历和历史记录不会随代码同步到 GitHub。

## Je veux préparer avec l’assistance / 我要辅助准备

1. Complétez coordonnées, disponibilités, postes et lieux ; ajoutez le CV puis **Enregistrez** le profil.
2. Gardez **start.bat** ouvert. Dans le navigateur dédié, connectez-vous à ChatGPT. « Navigateur détecté » ne vérifie pas la connexion à votre compte.
3. Cherchez des offres, lancez leur revue et lisez les recommandations. Le vert et l’orange demandent tous votre décision humaine. Confirmez ou écartez les offres. Match fort signifie pertinence, pas autorisation d’envoi.
4. Ajoutez les offres confirmées à la file et préparez-en une. Le panneau prochaine action montre la candidature et son étape.
5. Reprenez la page, vérifiez CV, lettre et réponses, puis envoyez vous-même sur le site du recruteur. Revenez confirmer l’envoi.

准备资料与本机简历 → 登录专用浏览器 ChatGPT → 阅读复核并确认岗位 → 准备队列 → 接管、检查、在招聘网站提交 → 回来确认。准备完成不等于投递完成。

## Si quelque chose bloque / 遇到问题

- **Données absentes** : vérifiez que start.bat tourne toujours et rechargez l’application. Un résultat absent ne signifie pas un succès.
- **Site externe inaccessible** : vérifiez Internet et réessayez plus tard. Consultez le diagnostic de scan pour les sources sans résultat.
- **Navigateur dédié non détecté** : lancez start.bat pour l’assistance. Vous pouvez toujours postuler manuellement.
- **Erreur de préparation** : l’outil n’a pas pu préparer le formulaire. Ce n’est pas un refus du recruteur. Reprenez ou ouvrez le site dans votre navigateur habituel.
- **Page déjà fermée** : la reprise peut ouvrir une nouvelle page ; les anciennes réponses ne sont pas restaurées. Si vous avez déjà envoyé, confirmez ici au lieu de renvoyer.
- **Besoin d’un autre avis** : exportez les résultats HTML/Excel dans la langue souhaitée. L’export ne valide pas les offres automatiquement.

数据加载失败时检查 start.bat 与网络，不要把没有返回当作成功。准备失败不代表被拒；网页重开不会恢复旧回答。已经成功投递的直接记录，避免重复投递。复核结果可导出给别人阅读。
