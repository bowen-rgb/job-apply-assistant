# Dashboard design references

V8.3 draws on established interface patterns without copying their source code or assets.

- [Tabler Admin Template](https://tabler.io/admin-template): responsive sidebar layout, clear cards and consistent controls. This project retains its own visual design and plain JavaScript stack.
- [i18next documentation](https://www.i18next.com/overview/getting-started) and [fallback guidance](https://www.i18next.com/principles/fallback): language switching, persistent preference and a defined fallback. This small local application uses its own bundled JSON catalogs and does not add a runtime dependency.
- [job-application-tracker](https://github.com/cankurttekin/job-application-tracker): search, saved applications, Kanban stages and analytics as useful job-search dashboard concepts. V8.3 adds clickable status metrics and makes the existing local pipeline easier to scan.

No code, styles, translations or artwork were copied from these projects.
