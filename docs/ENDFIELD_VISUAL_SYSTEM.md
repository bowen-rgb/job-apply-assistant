# 终末地视觉统一 · 2026-10-25

用户要求恢复菜单原项目配色，并重新设计整个界面；本记录覆盖此前浅青、暖黄的视觉方向。功能、导航、档案数据、扫描和申请逻辑不变。

- [Refactoring UI skill](https://github.com/edisonmbli/refactoring-ui-skill)：遵守既有原生 HTML/JS/CSS 和设计变量，检查阅读对比、主次动作、分组与边界，没有加入 Tailwind 或 UI 框架。

## 统一层

`static/endfield-ui.css` 是最后加载的配色层，复用 `--bg`、`--panel`、`--text`、`--aa-*`、`--ref-*` 和 `--ui-*` 变量。旧安洁莉娜主题中的强制颜色和圆角改为允许最终主题覆盖；硬编码的浅蓝色局部回归设计变量，避免多个主题争夺同一组件。

- 顶部导航、菜单、标题区为炭黑；主要动作亮黄，次要动作深灰，阅读区域浅灰白。
- 岗位、个人资料、队列、引导、PFE、工作台及二维码、账号、待处理等弹窗共用视觉层。官方主视觉只放在背景和标题的独立图像区域，不垫在正文下面。
- 绿色、红色、琥珀色保留为状态色；状态文字继续存在，不把所有状态都染成黄色。
- 安洁莉娜保留在头像、菜单卡片、播放器和部分标题的小插图；现有图库和显示模式不删。
- 原有动画、鼠标视差、Tab 返回、播放器、定位授权、18 个功能入口及小屏卡片菜单保留。

## 菜单文字修正

底部弧形按钮原先沿用原作四字标签的逐字坐标，换成业务标签后偏离按钮中心。现在两个标签分别使用舞台坐标 826 与 1126，独立居中，并限制在各自 208px 文字区内。

文字适配读取实际 SVG `getComputedTextLength()` 与 `getBBox()`，同时考虑粗体汉字的笔画外延。有空格的长标签可在词间分两行，中文可按字分行；无空格的西文单词整体缩放，避免把 Connexions 等从中间拆开。右侧标签宽度限制 95px，检查基线及卡片底部边界。

新增浏览器检查覆盖六种语言的字宽、中心、边界，主题颜色、官方图像是否真正覆盖到页面，以及原有导航和播放器。桌面、手机和隐藏弹窗沿用已有功能回归与截图检查。

网页端刷新后加载新样式；桌面安装包另行打包，修改源码不会覆盖已安装应用。
