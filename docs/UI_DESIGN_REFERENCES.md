# UI 设计参考约定

用户指定参考：[edisonmbli/refactoring-ui-skill](https://github.com/edisonmbli/refactoring-ui-skill)，2026-10-20 阅读其 README 和 [SKILL.md](https://github.com/edisonmbli/refactoring-ui-skill/blob/main/skills/refactoring-ui/SKILL.md)。这是独立、非官方的设计规则项目，不代表原书作者背书。这里只记录参考入口，没有执行其脚本或安装依赖。

后续修改界面前，先识别现有技术栈、设计变量、组件和主题；本项目为原生 HTML / JavaScript / CSS。沿用已有设计语言，不照搬示例颜色，不为参考资料引入 Tailwind。

设计与检查顺序：信息层级 → 布局和间距 → 字体排版 → 色彩与对比 → 深度 → 图像 → 空状态和收尾。先确定用户的下一步及一个主操作，再安排辅助信息和次要操作。组间距大于组内间距；状态需有文字，不只靠颜色。错误、空状态、等待状态要说明用户下一步。

需要具体数值或规则编号时，读取该仓库相应 reference 文件，不能凭摘要编造规则编号。涉及界面修改时，在桌面和手机宽度截图核对；只看源码的发现明确记为未验证。其设计规则与用户要求的视觉方向共同使用，避免只增加装饰、却不减少操作负担。

2026-10-20 新增 [Angelina 素材与界面改进](ANGELINA_UI.md)：在既有主题上统一标题、表单、主要动作、弹窗及新手导航，使用用户提供的静态素材，动效按实际任务和系统偏好启停。桌面和手机页面、动态弹窗均做渲染验证；覆盖范围和限制以该记录为准。

当前视觉方向以用户 2026-10-21 最新反馈为准：参考[鹰角官方夏活“安洁莉娜的旅行小记”](https://ak.hypergryph.com/news/8571)的浅青、蓝、黄旅行手帐视觉，以可爱柔和为主，工业细节只用于真实信息结构。历史深侧栏/整页网格不再是当前主题；详见 ANGELINA_UI.md 最后一节。

2026-10-24 导航方向：接入 [endfield_menu](https://github.com/ccdr4gon/endfield_menu) 总菜单，移除侧边栏。轮盘仅切换对应页面，不触发扫描、复核或投递；保留现有安洁莉娜素材、头像与图标。小屏采用同一入口清单的卡片菜单，顶部保留档案及语言切换。任何简化不得删除已有功能入口，详细映射、许可与验证见 [总菜单接入记录](ENDFIELD_MENU_INTEGRATION.md)。

2026-10-25 补充交互：Tab 呼出／收起，鼠标轻微视差；编辑表单时保留常规 Tab 行为。原游戏体力等装饰区可放真实本地时钟，中心放音乐／定位地图切换，不虚构数据。保留安洁莉娜素材。小型播放器控件保持稳定可点，不让视差牺牲操作准确性。

2026-10-25 最新配色要求优先于历史夏季浅青方案：菜单恢复 endfield_menu 原有炭黑 `#1A1C1E`、亮黄 `#FFDE00`、橙色 `#FD7500` 与冷灰白；业务页使用同一组设计变量，黑色标题区、浅灰阅读区、黄色主要动作。使用终末地官方主视觉、背景和纹理，保留安洁莉娜头像及适量小插图。图像来源见 [素材说明](../static/artwork/endfield/NOTICE.md)，实现和检查见 [终末地视觉统一](ENDFIELD_VISUAL_SYSTEM.md)。菜单须检查中法两种语言文字的实际 SVG 字宽、中心和边界，不能只按字符数估算。

2026-10-25 语言范围：界面、引导、弹窗和核验导出只保留中文与法语，删除其他四种界面文案及目录文件。旧语言偏好回退到受支持语言；岗位原文、简历和候选人的语言技能不受影响。
