| 参考文件 | 采用与调整 |
| --- | --- |
| ThinkingAccordion.tsx | 借鉴平滑展开；原生 details + ::details-content 的尺寸过渡，200ms。不支持 interpolate-size 时仍可原生展开。保留键盘与 ontoggle，不强制锁定用户展开状态；独立滚动的数据表和导入记录排除，避免裁切/滚动重置。 |
| SegmentedControl.tsx | 侧栏选中背景按实际按钮位置在 180ms 内移动；支持手机两列、动态尺寸、语言与导航状态变化。复用现有岗位统计条，不再叠第二套指示器。 |
| ClaudeMotionPresets.ts | 按钮原有短弹性释放保留；切页改成 6px/200ms 滑入与淡入，弹窗 220ms 轻量缩放；按场景区分而非一律强弹跳。 |
| StatusIndicators.tsx | 只在 cards 的实际 aria-busy 与真实扫描 running 状态显示活动点；读取提示延迟 350ms，避免瞬时闪烁。不冒充百分比，不提前显示成功。 |

二维码选择另一份申请时补同样的详情过渡，不在轮询重画中反复播放。切页只从显式 showView 调用，工作台刷新保持滚动与焦点。连续切换会取消旧动画；用户输入、按钮、原生详情的读写行为不因动画延迟或复制。

用户本轮明确要求：核心操作动画不能被操作系统“减少动态效果”关闭。因此新 UI 动效与已有按钮反馈按产品策略保持开启；已新增系统 reduced-motion=reduce 下仍有切页/导航/详情动画的检查。只有用户在平台内主动选择简洁模式才关闭这组 UI 动画。素材 GIF 仍属于独立的装饰显示偏好；本轮没有强制所有角色一直播放，也未开启任何投递任务。

保留原生 HTML / JS / CSS，没有引入 React、Framer Motion 或 Tailwind。样式在 motion.css；新 UI 过渡在 interaction-refinements.js。文档中此前的覆盖清单是历史快照，本记录说明本轮新增，不能解读为整个参考库已全部移植。
