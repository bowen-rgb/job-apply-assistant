# 扫描、复核和同机共享工作台

## 2026-10-22 恢复入口

对照桌面版引入前的 `42c8963`：功能处理器仍在，但扫描按钮所在的岗位侧栏随页面隐藏，简洁模式额外隐藏复核、岗位导航、批量准备、资料设置和筛选。改为：

- 侧栏靠上始终显示“启动岗位扫描”，运行时显示扫描状态，防止重复启动。
- 侧栏“让 ChatGPT 复核岗位”跳转到“求职进度与队列”的复核区。
- 队列复核默认仅处理队列内尚未复核、未提交的岗位；可选择已收藏与高度匹配或仅收藏。复核不会提交申请。
- 简洁模式保留所有已提供的导航、筛选、批量准备和设置入口；改变引导方式，不移除功能。
- 保留二维码、批量导入/删除、图片放大、人工确认、导出、来源诊断、个人档案和待处理入口；这些功能没有被替换。

## 同一台电脑，一个后台

桌面与 start.bat 均使用 `http://127.0.0.1:8765`。`/api/runtime` 返回应用身份、资料目录和 PID，用于确认复用的是同一资料目录的后台，而非只因为端口有响应就接管。

桌面菜单“在浏览器打开同一工作台”打开同一个地址。桌面可复用已运行的网页后台；复用时退出桌面不会杀掉别的进程。由桌面启动的后台随桌面退出而停止，浏览器会显示连接失败，资料仍保留。

网页每六秒读取扫描、岗位和队列状态，切回窗口时也会同步；不自动覆盖正在编辑的个人资料表单，不刷新招聘网站登录页。另一客户端切换档案时，本地工作台重载到后台当前档案，避免把旧档案操作写给其他人。

安装包必须携带当前 app/static 文件。仅改项目源码不等于已更新已安装的桌面程序；本轮重建安装包并更新本机安装后验证。
