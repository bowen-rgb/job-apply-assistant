# 浏览器 Dashboard

不再使用 Electron 或单独的桌面安装包。网页与快捷方式打开同一个本地后端，沿用同一份档案、简历、账号与申请记录。

第一次使用运行 `run_windows.bat` 准备环境。现有环境无需重新安装：双击根目录 `setup_dashboard.bat`，生成桌面及开始菜单快捷方式，并登记 Windows 的卸载入口。

- **打开**：桌面「Job Apply Dashboard」或 `start.bat`。后台隐藏运行；已有后台会复用，多次点击不会启动多个后台。不再每次打开专用 Chrome 或重新加载登录页面。
- **停止**：开始菜单「Stop Dashboard」或 `stop_dashboard.bat`。结束本项目管理的后台任务，保留 Chrome 登录窗口。浏览器关掉后，后台仍会运行，进行中的任务不会因关闭网页而突然中断。
- **移除入口**：`uninstall_dashboard.bat` 或 Windows「已安装的应用」中的 Job Apply Dashboard。先停止后台，再删除快捷方式与卸载登记。项目目录、Python 环境及所有个人资料保留，以便恢复使用。
- **排错**：查看 `data/server-logs` 最新日志。启动不成功时会显示错误提示。停止操作核对实例和进程身份，不会按端口强杀其他 Python 或 Chrome。

旧 Electron 如已安装，可从 Windows 的「已安装的应用」卸载 Job Apply Assistant；保留旧资料目录。轻量启动器会读取旧版保存的工作目录，避免换成空白档案。

## 保留的业务能力

扫描、来源管理、自动复核、队列准备与接管、二维码批量导入、账号登录、简历和动机信、导出、申请追踪均由原后端提供。复核随队列自动执行，不要求逐条人工确认。岗位页原统计栏显示「已投递等待中／有回复面试／待跟进／待决定／被拒」；每个数字点击后打开相同口径的列表。「被拒」必须有已投递记录及招聘反馈，匹配较低、准备失败或过期不算被拒。

轮盘仅负责导航，保留音乐、时钟、动效与安洁莉娜素材；移除地图。全站仅保留中法界面。

## 原生岗位采集

`app/vendor/jobspy` 保存 MIT 授权的 JobSpy 采集器源码，版本及原始文件校验值见同目录 `UPSTREAM.json`。不再调用安装包的 `scrape_jobs`、CLI、MCP 或 pandas；由 `app/job_board_worker.py` 直接调度对应站点采集器，输出本项目的岗位记录。保留进程隔离、超时、重试、诊断、去重和匹配流程。

可选依赖通过 `requirements-jobspy.txt` 安装。来源可用性取决于网站权限、登录及网络状态；阻挡不会被记录为成功的零条岗位。

## 高度匹配岗位自动入队

岗位页“启动岗位扫描”结束后，会自动处理仍可申请、未入队的高度匹配岗位。也可点击“批量处理高度匹配岗位”处理已有扫描结果。每份岗位先由 ChatGPT 复核，有疑点最多再审一次；只有 APPLY 才进入准备队列，SKIP 跳过，仍缺信息的保留而不入队。已投递、已关闭、已忽略、用户否决及已有队列记录均排除。相同档案和岗位的有效复核会复用，不在准备时重复消耗。

状态区显示当前岗位、进度、入队／不适合／信息不足的数量，并可停止。连接、登录或解析失败会暂停本轮，不对余下岗位连发请求。此流程不打开申请表，也不提交申请。HTTP 接口为 `/api/matches/automation`（GET 状态、POST 启动）及 `/api/matches/automation/stop`（POST 停止）。

该链路由平台后端独立运行，不依赖 Codex 会话。需要网页 ChatGPT 时，平台会复用或启动专用 Chrome；已打开的登录页不会被循环刷新。检测通过只加入准备队列，不等于发送申请。

2026-10-31 流程补齐验证：406 项全量检查中，一项旧版法语提示断言过时，更新后相关 11 项复测通过；专用 Chrome 自动启动和原生后台调度另经 5 项流程测试验证。24 个轮盘入口（含滚动后条目）均以真实鼠标点击验证。此轮在本机启动的是平台自己的复核工作进程，Codex 没有逐条操作招聘网站。

批量按钮始终保留在扫描按钮旁。运行时显示进度；暂停或异常时可直接继续／重试。新版工作进程会记录已经完成的复核：档案和岗位未变化时，恢复同一批次不重复处理这些结果。运行中的旧后台继续完成自己的任务，后台维护更新在下次正常启动时载入。
