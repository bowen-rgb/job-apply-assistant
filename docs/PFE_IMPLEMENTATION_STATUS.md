# PFE 升级验收清单

更新：2026-10-19。区分代码实现与真实外部网站验收，不能用本地测试通过代替渠道实测。

## 已实现

- 独立候选人档案、简历库和技能记录；四方向简历标签路由及无匹配时的默认简历。
- 按方向和法英术语生成查询，分配全网、科研、ATS、学生和团队发现预算。
- JobSpy internship 发现；ABG、Inria、CEA、GDR 公开渠道和 PDF 读取。
- 持续机会库、来源记录、跨站去重、原页核验时间和关闭状态。
- 资格、时间、技术任务、研究内容、博士衔接五项证据；缺少信息仍待核验。
- 研究团队与学校公告独立保存，不把未确认名额当成岗位。
- 已发现来源复用及 Greenhouse、Lever、Ashby board 识别。
- 移除全局短合同偏好，普通求职时长按档案配置。
- 导入技能保留自评、实践待核、基础待确认、团队技术、学习目标等状态；向复核和求职信提供这些边界。

## 部分完成或待验收

| 项目 | 真实状态 | 还需要做什么 |
| --- | --- | --- |
| 法国来源覆盖 | 已有适配和失败诊断，尚未完成本轮真实扫描验收 | 检查各来源能否返回可申请且适合候选人的原始岗位 |
| 学校私有渠道 | 有学校入口和公告导入 | 使用者提供学校入口并自行授权登录；未实现校内全量采集 |
| SearXNG | 可配置并回退到原有引擎 | 配置可用实例并实测，不是内置稳定搜索服务 |
| 深度语义匹配 | 本地技术概念规则，加现有 ChatGPT 二轮判断 | 尚无独立语义检索模型或针对真实岗位集的质量评测 |
| 团队、导师反向发现 | 搜索与线索库已实现 | 尚无论文、课题、导师关系的完整学术检索系统 |
| 持续有效性 | 四小时后标记旧证据，启动扫描时有界复查 | 不是每四小时自动全库巡检；需后续调度及限流设计 |
| 一键自动投递 | 保留已有准备、审批、接管和回执机制 | 不是所有网站的一条龙；登录、验证码和表单差异需实测，未开展本轮真实投递 |
| 运行中的本地服务 | 文件更新与资料导入可持久保存 | 服务重启后才能使用新加载的后端逻辑 |

个人简历、技能表、备份与联系方式仅保存在本机候选人数据目录，不进入 GitHub。查看操作方法见 [PFE 使用说明](PFE_DISCOVERY.md)。
