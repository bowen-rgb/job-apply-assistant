# 总菜单接入记录 · 2026-10-24

本次菜单只负责导航。用户原有安洁莉娜素材、头像、图标、页面业务逻辑和设计变量保留；不通过菜单自动开始扫描、复核、填表、提交或修改岗位。

## 来源与边界

参考 [ccdr4gon/endfield_menu](https://github.com/ccdr4gon/endfield_menu)，固定版本 `8d3f3ae592c9573da888599fb4e1b9804f0e2e36`。这是爱好者复刻项目，不能把它等同于经过大型产品验证的框架。

其 GPL-3.0-or-later 菜单源码作为独立文档放在 `static/vendor/endfield-menu/`，保留 LICENSE、修改标记和 NOTICE。上游明确排除授权的 button-art.js、backdrop-field.js、card-contours.js 未引入；卡片插画使用现有本地素材，图形使用上游可授权的 shared-defs 图标。第三方菜单自身的许可不用于声明其他应用文件的许可。

## 数据与生命周期

菜单统计读取当前档案的真实岗位和队列，读取失败显示不可用并可重试。菜单打开时定期更新，隐藏时暂停统计轮询和场景动画。场景只加载一次，返回菜单不刷新浏览器或重新加载用户正在登录的页面。返回原页保留尚未保存的表单。

场景以 sandbox 隔离（脚本和外链窗口可用，未授予同源权限），通过随机令牌、消息来源校验和入口白名单连接父页。只传显示名称、翻译标签和统计，不传邮箱、密码、简历、授权凭据。既有应用内安静模式保留。2026-10-25 增加的定位地图仅在主动点击定位后加载外部地图，其余菜单操作不自动访问外部服务。

## 2026-10-25 修复与交互补全

故障原因是后端给菜单 HTML 也加上了 `X-Frame-Options: DENY`，导致 iframe 被浏览器拦截。旧测试直接模拟静态文件响应，遗漏了真实中间件响应头。现在菜单文档单独使用 HTTP CSP `frame-ancestors 'self'`，其余文档/API 保留 DENY。浏览器测试已改为经过真实 FastAPI 静态文件和安全中间件，修复前可复现空白，修复后可点击页面。此外，在本机实际 HTTP 地址进行了静态资源、场景显示、页面点击和 Tab 往返验证；API 使用测试资料，未写入候选人数据。

- Tab / Esc 呼出或收起菜单；编辑输入框、选择框、音频控件及打开弹窗时保留原有键盘行为，Shift+Tab 不被接管。返回原页保留未保存内容。
- 保留鼠标弹簧视差，播放器控制区固定在前景，避免小按钮随视差移动而点不中。
- 统计更新不再重播入场动画。场景加载超过 5 秒仍不可用时自动显示完整卡片菜单。
- 本地时间及日期每秒更新，不写死时区，使用用户浏览器时区。
- 中心支持本地音乐播放、上一首／下一首、多曲选择；音频使用浏览器 Blob URL，不上传，重新选择时释放旧 URL。不预置版权音乐，也不自动播放。
- 地图与音乐可手动切换，可勾选每 30 秒自动轮换。只有点击“显示我的位置”后才申请定位权限；权限拒绝时说明下一步。坐标只保留在当前页面内存，可主动清除。
- 内嵌地图使用 [OpenStreetMap 官方分享嵌入方式](https://wiki.openstreetmap.org/wiki/Export#Embeddable_HTML)，并提供 [Google Maps URL](https://developers.google.com/maps/documentation/urls/get-started) 外链。没有把需要 API 配置的 Google Maps Embed API 伪装成已接通。地图加载会把位置传给地图服务，界面在定位前明确提示。
- 自动化验证覆盖真实响应头、Tab 往返、视差变化、播放列表切换、无定位时无地图请求、授权／拒绝／清除位置、轮换、统计不重播动画和场景失败降级。
