目标：让第一次使用的人知道“现在在哪、下一步点什么、何时需要接管”。保留现有原生 HTML/JS/CSS、候选人隔离、真实统计和投递授权边界。

素材盘点：Angelina.rar 共 48 文件（10 PNG、10 GIF、28 UI PNG），无字体、脚本或说明。完整收录所有素材，页面按任务选用角色与少量贴纸，原文件不改图；不把贴纸里的字当功能标签。

## 设计约束

主内容：真实状态、当前任务、下一步；次内容：简历和岗位依据；装饰最后。小步导航只切页，不发申请，不创建虚假成功提示。单个操作区保持一个主按钮。

颜色沿用现有背景、文本、语义状态 token；品牌用素材暖橙 #f3b368 与深铜 #94451f，墨色 #202733，白色内容面板。文字 Segoe UI/Microsoft YaHei，标题 Bahnschrift 配合系统中文字体，数据 Consolas；无网络字体和新框架。

间距 8/12/16/24/32/48；正文字号 14/16，标题 24/32；最大说明行宽 65ch。风格标记是任务关联的 Angelina 场景插图，周围界面保持克制。小屏缩小图片，保留任务与操作；减少动效偏好和简洁模式均停止 GIF。

实现覆盖：工作台、岗位、资料、队列、PFE、新手页、账号、待处理、二维码及动态弹窗。原有图表只显示真实数据，角色动画不冒充任务进度。


## 验证与边界

已在真实浏览器渲染的模拟数据界面检查岗位、资料、队列、新手页、工作台、PFE、账号和待处理弹窗、二维码、账号编辑器及独立 Gmail 配置指引。尺寸包括 320/375/768/1280/1440，截图不包含用户个人资料。岗位/队列等主要页面保留原有信息与动作，导航不调用申请或扫描接口。图片按需加载，默认静态，显示偏好按候选人保存；简洁模式隐藏插画并收回图像栏。少量低分辨率贴纸只作小装饰，不拉伸到内容区。

检查项目包含：横向溢出、窄屏折叠菜单、分区键盘跳转、六语切换、弹窗滚动、图片不覆盖标题、原有表单值不被装饰重绘、原有复制错误反馈、导入无发送、三步导航无写操作。动态图的正向测试使用模拟正在处理状态，减少动效与简洁模式均回到 PNG。此次未运行真实投递。

新配色对比度：白字/深铜、深铜/浅橙、墨色/暖橙、浅字/墨色均实测超过 4.5:1。没有完成逐像素的全站可访问性认证；原有语义状态颜色保留。外部招聘网页不在本项目样式控制范围内。

本轮发现中“源码待截图”的主要页面与弹窗均已渲染复核；截图作为独立预览保存在 docs/assets/angelina/。素材选用与来源详见 static/artwork/angelina/manifest.json。未执行参考仓库脚本，未新增框架、远程字体或运行依赖。

## 2026-10-21：工业元素与完整素材库

用户反馈上一版风格割裂，且素材覆盖不完整。这轮恢复低对比工业网格、窄半径面板、切角与真实流程编号；暖橙角色元素进入同一套材质与间距，不把工业装饰整体删除。

完整保留素材包 48 张原始文件：10 静态角色、10 动图、28 UI 贴纸。原图未改绘，映射在 manifest.json，目录在 catalog.json。角色用于页面任务和空态；所有素材可从左侧“场景与贴纸”预览，并按页面选用或恢复自动搭配。设置按候选人保存，不进入个人资料、CV 或岗位匹配。贴纸置于图像留白栏，不压住正文和控件；不是把 48 张图同时铺上页面。素材预览动图单独标明不代表申请进度。

二维码不再套用整页插画标题模板，而使用紧凑的导入工作台；具体改动和交互验收见 QR_APPLICATIONS.md。新增素材库浏览器测试覆盖 48 项数量、文件存在、动图预览、按页应用、保存恢复、重置与窄屏滚动；全部没有业务接口写操作。


最终验证：215 项全量测试通过；二维码窗口最后调整另通过 3 项浏览器测试。导入记录在全部成功后自动收起，失败时展开，手动展开或收起会保留，给当前岗位与简历留出空间。全局取消隐式平滑滚动，避免刷新恢复焦点时把正在阅读的位置拉走。

新版预览：[二维码批量桌面](assets/angelina/qr-desk-1280.png)、[二维码批量手机](assets/angelina/qr-desk-375.png)、[完整素材库](assets/angelina/material-gallery-1280.png)。本地服务已在无活动任务时隐藏重启，新选岗接口与 48 项目录已验证可用。
