# 毕业实习与科研机会

在侧栏打开 **毕业实习与科研机会**。这条流程用于法国 M2、PFE、工程师毕业实习；普通求职仍使用原来的岗位页。

## 第一次使用

1. 在左侧下拉框选自己的档案。不同人的条件、机会库、联系人和投递记录分别保存。
2. 打开“机会发现条件”，启用毕业实习模式，选择专业方向和地区。例如：控制、机器人、机械与仿真；France；2027-02；6 个月；开始时间可浮动 1 个月。
3. 如果希望以后读博，勾选积累科研经历。只填写自己真实掌握的技能。
4. 点击“保存发现条件”。这一步只保存并重新分析本档案已有的实习记录。
5. 点击“扫描机会”才会联网搜索。可以展开“发现计划”查看实际查询，并在岗位页查看来源运行诊断。来源失败、没有结果、尚未执行是不同状态。
6. 在“已发布实习”查看证据、日期和五项评分；在“研究团队线索”查看尚未确认名额的团队。学校内部公告可用“导入学校或导师发布的信息”保存。
7. 核对原页和个人资格后，进入岗位页使用原有人工确认、材料审批及准备队列。保存条件、导入公告、修改联系状态都不会提交申请或发送邮件。

没有简历或邮箱也可以找机会；准备完整申请仍需补齐材料。学校入口需要使用者自己的登录权限。

## 普通求职的时长设置

“个人资料与偏好 → 可工作时间”增加最短、最长时长（月），留空表示不限。没有默认的四个月上限，也不会默认给短合同加分、给长合同减分。新建档案不再默认启用法国短工网站和临时工作来源。

已有档案明确填写的合同类型、结束日期、排除条件和网站设置继续保留。不会根据姓名或另一个人的条件迁移限制。旧的 AI 复核结果属于历史判断；修改条件后应重新复核，历史投递及招聘方反馈不被重写。

毕业实习模式以该模式的目标时长为准。岗位写“5–6 个月”可与目标 6 个月匹配；“要求有 6 个月经验”不算合同期限。没有明确日期、学历或地点证据时保留待核验，不伪造符合条件。

## 实际实现

| 需要 | 实现 | 边界 |
| --- | --- | --- |
| 按专业找 PFE | 六组法英方向、跨方向技术任务词、五类渠道轮转分配查询预算 | 本地规则和现有 ChatGPT 二轮复核；没有新建向量模型 |
| 普通招聘发现 | 复用 JobSpy，PFE 使用 internship 类型和方向词，补充 Bing、DuckDuckGo | 平台限流或缺少可选依赖会显示诊断，不保证平台覆盖 |
| 科研实习 | ABG、Inria、CEA、GDR-IHM 公开入口，研究域查询，读取公开 PDF | 某个入口变动或封锁会报告失败；没有绕过登录或验证码 |
| 学生专属渠道 | JobTeaser 公开发现、学校入口、粘贴公告导入 | 不声称能读取学校内部全部职位；导入文本标为未核验 |
| 反向发现团队 | 团队/课题独立线索库、原文、联系人和手动跟进状态 | 无明确招聘公告的团队不会变成已发布岗位或进入投递队列 |
| 持续机会库 | 复用候选人 SQLite 岗位、原始来源与跨站去重；附加证据、核验时间、来源注册表 | 不将搜索结果总数视为真实岗位总量 |
| 来源增量维护 | 自动识别 Greenhouse、Lever、Ashby 的 board；下次扫描复用；有界重查已发现网站 | ATS 每日轮询最多 10 个；网站查询也受每轮预算约束 |
| 岗位真实性 | 明确区分读取原页、未核验、核验过期、原页关闭 | 读取原页不等于确认仍可提交；403/访问失败不等于关闭或拒绝 |
| 五项判断 | 广告资格证据、时间、技术任务、研究内容、明确博士衔接措辞 | 候选人资格仍须核对；实验室名不等于博士名额或资助 |

核验超过四小时显示过期。用户启动扫描时最多复查十条旧证据，也可手动点击“重新核验原页”。这不是每四小时自动运行的后台服务。404/410 或明确过期信息更新岗位可用性，不创建招聘方拒绝记录，也不修改已投递、面试等历史状态。

公开 HTML/PDF 读取有超时和大小限制，拒绝私网地址及指向私网的重定向。活动申请或已建立发送事务的岗位不会在核验过程中改写其申请材料。

## 可选配置

- **JobSpy**：沿用项目可选依赖安装方式；未安装时有明确提示，其他渠道仍可运行。
- **SearXNG**：可填自己部署且允许 JSON 查询的实例。允许 HTTPS 公网地址或明确配置的本机实例。只发送专业方向查询，不上传简历。实例失败会记录并回退到现有搜索引擎。公共实例不一定开放 JSON。
- **学校入口**：填写学校 Career Center 的公开入口链接，之后自行登录。不要把密码或会话令牌写入网址。

## 参考与取舍

参考公开机制，未复制这些服务的私有数据库或采集服务：

- [Simplify 实习库维护规则](https://github.com/SimplifyJobs/Summer2027-Internships/blob/dev/CONTRIBUTING.md)：持久化机会记录、来源、开放状态；其主要市场不等于法国 PFE。
- [JobSpy](https://github.com/speedyapply/JobSpy)：复用平台采集层，PFE 判断由本项目完成。
- [ABG](https://www.abg.asso.fr/fr/candidatOffres)、[Inria](https://jobs.inria.fr/public/classic/en/offres)：科研实习原始渠道。
- [Simplify Copilot](https://help.simplify.jobs/articles/2415391-using-copilot-to-autofill-applications)：复用候选人资料的准备流程，结合本项目已有材料审批与发送回执。
- [SearXNG 搜索接口](https://docs.searxng.org/dev/search_api.html)：可配置查询，而非假设所有公共实例稳定可用。

实现入口：`app/constraints.py`、`app/pfe.py`、`app/pfe_discovery.py`、`app/pfe_config.py`；接入现有 providers/searcher/scan_manager/reviewer；界面为 `static/pfe.js`、`static/pfe.css`。

本轮没有运行真实扫描、发送申请、注册账户、重置密码或发送邮件。自动化提交沿用既有审批和回执流程，本模块没有扩大其授权范围。
