Filtres & contraintes

CV

Bibliothèque locale. Le CV actif est celui envoyé par le pré-remplissage.

Exemples de tags : accueil, logistique, data, mécanique, retail. Sans correspondance, le CV actif reste utilisé.

Le CV sélectionné et les informations du profil sont transmis à votre session ChatGPT pour rédiger la lettre.

Réponses réutilisables

Pour les questions répétitives non sensibles. Elles ne sont remplies que si le libellé correspond clairement.

Les questions de santé, handicap, origine, religion, politique, syndicat, orientation sexuelle, casier, autorisation de travail et attestations légales restent toujours manuelles.

Profils de recherche

Agent fallback (formulaires complexes)

ChatGPT Web peut planifier des actions sur les formulaires difficiles. Le moteur local valide chaque action et bloque toujours Submit, CAPTCHA/MFA, création de compte et questions sensibles/légales.
